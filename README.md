# 雲海に浮かぶ浮遊城 — 3Dボクセルアート壁紙 (Floating Citadel Voxel Wallpaper)

外部ライブラリや CDN に一切依存しない、純粋な静的 HTML / CSS / Vanilla JavaScript + WebGL で構築されたフルスクリーン動く 3D ボクセルアート壁紙です。

## 特徴

- **外部依存ゼロ・ビルド不要**: 外部パッケージ・CDN・Web フォント・外部通信を使用せず、静的ファイルを配置するだけでそのまま動作します。
- **立体 3D ボクセルシーン**:
  - **巨大な浮遊城**: 逆円錐状の岩盤・水平プラットフォーム・尖塔群・多層城塞シルエットと、夕景〜夜間に灯る窓明かりを備えた浮遊要塞。
  - **流れる雲海**: 複数レイヤーの立体ボクセル雲が異なる速度でシームレスに流れます。
  - **遠景の樹海と山脈**: 大気フォグで奥行きを表現した広大な森と稜線。
  - **手前の崖・揺れる草・滝**: 風に揺らぐ草ボクセルと、断崖を流れ落ちる滝・水しぶきパーティクル。
  - **光演出**: 雲間から差し込む光の筋（ゴッドレイ）と空間を漂う光粒。
- **朝・昼・夕焼け・夜の時間帯変化**: 空のグラデーション、太陽光／月光、環境光、フォグ、雲影、城の灯りが滑らかに連動変化します。
- **壁紙向けステルス UI & 省電力対応**: 通常時は UI を一切表示せず、タブ非表示時の自動描画停止や省電力プリセットを備えています。

## 使い方

### 1. ローカルで確認する

ES Modules を使用しているため、ローカルの簡易 HTTP サーバー経由で開いてください。

```bash
python3 -m http.server 8080
```

ブラウザで `http://localhost:8080/` を開くとフルスクリーンで表示されます。

### 2. HTTPS 静的ホスティングへ配置する

`index.html`、`css/`、`js/` をそのまま任意の静的ホスティングサービス（GitHub Pages、Cloudflare Pages、Netlify 等）へアップロードするだけで公開できます。ビルド工程は不要です。

### 3. デスクトップ壁紙として利用する

HTTPS の Web ページをデスクトップ壁紙として表示できるツールやサービスに、公開したページの HTTPS URL を指定して利用してください。必要に応じて後述の URL クエリパラメータを付与すると、好みの時間帯や省電力設定で起動できます。

## 操作方法

通常時は壁紙の視認性を妨げないよう、画面上に UI は表示されません。

- **`H` キー**: 設定パネルの表示／非表示を切り替え
- **画面右下隅クリック**: 右下隅の透明ホットスポット（`44px × 44px`）をクリックして設定パネルを開閉
- **`Esc` キー**: 設定パネルを閉じる

設定パネルでは以下の項目を変更でき、設定値は `localStorage` に自動保存されます。

- **時間帯モード**: 自動サイクル / 現在時刻連動 / 朝 / 昼 / 夕焼け / 夜
- **画質・省電力**: 高画質 / 標準 / 省電力
- **一時停止 / 再開**: アニメーションの停止と再開

## URL クエリパラメータ

URL にクエリパラメータを指定することで、初期表示時の設定を上書きできます（例: `?time=sunset&quality=eco`）。

| パラメータ | 指定可能な値 | 説明 |
| --- | --- | --- |
| `time` | `auto` \| `realtime` \| `dawn` \| `day` \| `sunset` \| `night` | 時間帯モードを指定します（デフォルト: `auto`） |
| `quality` | `high` \| `medium` \| `eco` | 画質・省電力プリセットを指定します（デフォルト: `medium`） |
| `paused` | `0` \| `1` | `1` を指定すると一時停止状態で開始します（デフォルト: `0`） |

## ファイル構成

```text
/
├── README.md
├── index.html          # フルスクリーン Canvas + ステルス設定 UI
├── css/
│   └── style.css       # フルスクリーンレイアウト・ダークグラス調設定パネル
└── js/
    ├── main.js         # 初期化・描画ループ・設定管理・省電力制御
    ├── math.js         # 3D 行列・ベクトル・補間ユーティリティ
    ├── shaders.js      # ボクセル・空・ゴッドレイ用 GLSL シェーダー
    ├── voxel-scene.js  # 浮遊城・雲海・森・崖・草・滝・光粒の生成
    └── renderer.js     # WebGL レンダラー・インスタンシング描画・リサイズ管理
```

## 動作要件

- WebGL2 または WebGL1 に対応したモダンブラウザ（Chrome / Edge / Firefox / Safari 等）
- JavaScript（ES Modules）が有効であること
- WebGL 非対応環境では画面中央に案内メッセージを表示します
