# 要件定義書 — 雲海に浮かぶ浮遊城 動く3Dボクセルアート壁紙

## 1. プロジェクト概要・目的

- **プロジェクト名**: 雲海に浮かぶ浮遊城 3Dボクセルアート壁紙（Floating Citadel Voxel Wallpaper）
- **目的**: HTTPS の Web ページをデスクトップ壁紙として表示できるツール／サービスに URL を指定して利用するための、**動く 3D ボクセルアート壁紙**を静的 HTML / CSS / Vanilla JavaScript（WebGL）で制作する。
- **公開・配布形態**: 外部ビルドツールや外部 CDN に依存しない静的ファイル群として構成し、ユーザー側の任意の HTTPS 静的ホスティング環境へそのまま配置・公開できる形にする。

---

## 2. 著作権・表現上の制約（必須）

- 特定の既存作品・IP の固有名詞、作品名、キャラクター名、ロゴ、既存画像アセットは一切使用・記載しない。
- 本ドキュメント、`README.md`、HTML のタイトル・メタ情報、ソースコード内の識別子・コメントに至るまで、すべてオリジナルの表現（「浮遊城 / Floating Citadel」「雲海 / Sea of Clouds」等）で統一する。

## 3. ビジュアル・3D ボクセルシーン要件

画面全体（フルスクリーン）で、雲海の上空にそびえ立つ巨大な浮遊城の遠景を、すべて **3D ボクセル（立方体の集合）** と自前 WebGL シェーダーによって立体的に表現する。

### 3.1 シーン構成要素
1. **浮遊城（Floating Citadel）**
   - 画面中央〜上部の遠景に鎮座し、「これから目指したい」と感じられる壮大な距離感と圧倒的な威容を備えた巨大な多層浮遊要塞。
   - **下部構造**: 非対称にうねり裂けた黒ずんだ破砕岩盤の逆円錐・垂下岩柱群と、最下端の空洞・崩れた岩アーチ構造（周囲に漂う浮遊岩盤破片を含む）。
   - **中層構造**: 放射状の装甲リブと外周装甲ブロックを備えた傾斜フランジ基部、左右へ細長く伸びる水平翼、その上およびフランジ周囲に林立する白銀のオベリスク状尖塔群と下面の鎖状ペンダント。
   - **上層構造**: 暗鉄・ダークグレー基調の 5 大階層ブロックと 4 本の深い水平くびれスリット、左右・斜め前へ非対称に張り出すバルコニー回廊、壁面の縦控え壁・銀灰装飾帯、および最頂部にそびえる深紅〜赤煉瓦色の多段王城。
   - 夜間や夕景では、各階層のスリット・バルコニー・頂上王城の一部に微かな窓灯り（発光ボクセル）が浮かび上がる演出を取り入れる。
2. **雲海と空（Sky & Sea of Clouds）**
   - 空の背景は時間帯に応じて滑らかに変化するシェーダーグラデーションで描画する。
   - 浮遊城のシルエットが映えるよう密度を抑えた複数レイヤーの立体ボクセル層雲（城の背後・中腹〜下部・中景の谷上空）を配置する。
3. **遠景の山脈と広大な森（Distant Mountains & Forest Valley）**
   - 画面下部〜中景の起伏のあるボクセル樹海・左右の山脈に加え、浮遊城の背後〜地平線にかけて低く連なる遠方の丘陵・遠景稜線を配置し（21:9 ウルトラワイドでも途切れない広がり）、大気フォグ（距離フォグ）によって遠近感・空気感を演出する。
4. **手前の崖・揺れる草・滝（Foreground Grassy Cliff & Waterfall）**
   - 画面手前（右下付近）に立体ボクセルの断崖と、その上を覆う草ボクセルを配置し、遠景の巨大な浮遊城との対比で壮大なスケール感を演出する。
   - **崖の滝と水流**: 高い断崖の上部（小川／水源）から放物線軌道を描きつつ画面下端を突き抜けて谷底の樹海レベルまで勢いよく流れ落ちる立体ボクセルの滝と、谷底〜崖下から立ち上る水しぶき・ミスト（ボクセルパーティクル）を表現する。
5. **光演出（Light Particles & God Rays）**
   - 雲の合間や浮遊城の背後から差し込む光の筋（ゴッドレイ）。
   - 空間をゆっくり漂う微細な光粒（ボクセルパーティクル）。

### 3.2 ライティング・質感
- 各ボクセルの面法線に基づくディレクショナルライト（太陽光／月光）＋半球環境光（空色・地面色）により、ボクセル特有のシャープな立体感と陰影を表現する。
- 距離に応じた大気フォグ（Exponential / Linear Fog）を適用し、手前の崖から遠景の浮遊城・雲海まで自然な奥行きを作る。

## 4. アニメーション・時間帯変化要件

壁紙として長時間眺めていても心地よく、かつ動きが感じられる以下のアニメーションを実装する。

1. **浮遊城の緩やかな浮遊**: 微細な振幅・長周期の sin 波による上下浮遊アニメーション。
2. **雲海の流れ**: 複数レイヤーのボクセル雲が異なる速度でゆっくりと水平移動し、画面端でシームレスにループする。
3. **手前の草の揺れ**: 風の波に合わせて手前の崖の草ボクセルが揺らぐアニメーション（頂点シェーダーによる軽量な変位）。
4. **滝の水流としぶき**: 高い断崖の上部から放物線軌道で画面下端を突き抜け谷底の樹海レベルまで流れ落ちる水流ボクセルの連続的な落下アニメーション（色・輝度の流れおよび位置ループ）と、谷底〜崖下から立ち上る水しぶき・ミストのボクセルパーティクル。
5. **光粒・光の筋の動き**: 光粒が緩やかに上昇・明滅し、光の筋が雲の動きや時間に合わせて柔らかく揺らぐ。
6. **時間帯の緩やかな変化（Time of Day）**:
   - **朝（Dawn）→ 昼（Day）→ 夕焼け（Sunset）→ 夜（Night）** の 4 フェーズを滑らかに補間する。
   - 時間帯に応じて、空のグラデーション、太陽光／月光の色・角度、環境光、フォグ色、雲の陰影色、光粒・城の灯りの明るさを連動変化させる。
   - 動作モードとして以下を切り替え可能にする：
     - **自動サイクル（デフォルト）**: 約 10 分周期（600 秒）で朝→昼→夕→夜を緩やかに循環。
     - **現在時刻連動**: 端末の現在時刻（0:00〜23:59）に合わせて時間帯を自動反映。
     - **時間帯固定**: 朝 / 昼 / 夕 / 夜 のいずれかに固定。

## 5. UI・操作要件（壁紙向けステルス UI）

壁紙として利用する際の視認性を最優先し、通常時は画面上に一切の UI を表示しない。

### 5.1 表示ルール
- **通常時**: 完全フルスクリーン表示（`100vw × 100vh`、`overflow: hidden`、UI 要素はすべて非表示）。
- **設定パネルの開閉**:
  - キーボードの **`H` キー** 押下で設定パネルの表示／非表示をトグルする（`Escape` キーで閉じる）。
  - 画面右下隅の目立たない透明ホットスポット（`44px × 44px`）のクリックでも設定パネルを開閉できる（キーボード入力が届きにくい壁紙環境でも操作可能にするため）。

### 5.2 設定パネルの項目
設定値は `localStorage` に保存し、次回読み込み時に自動復元する。また、URL クエリパラメータ（例: `?time=sunset&quality=eco`）での初期指定もサポートする。

- **時間帯モード**: `自動サイクル` / `現在時刻連動` / `朝` / `昼` / `夕` / `夜`
- **品質・省電力プリセット**:
  - `高画質 (High)`: 高 DPR（最大 2.0）・60fps 目安・全エフェクト有効
  - `標準 (Medium / デフォルト)`: DPR 最大 1.5・60fps 目安・バランス重視
  - `省電力 (Eco)`: DPR 1.0・30fps 上限・パーティクル数削減（ノート PC・長時間壁紙運用向け）
- **アニメーション一時停止 / 再開**: 静止画として固定したい場合用のトグル。

## 6. 技術要件・非機能要件

### 6.1 技術スタック・制約
- **構成**: 静的 HTML5 / CSS3 / Vanilla JavaScript（ES Modules または標準スクリプト）＋ **WebGL（WebGL2 優先、非対応環境向けフォールバック表示）**。
- **外部依存ゼロ**: 外部ライブラリ・CDN（Three.js 等）・Google Fonts・外部 API 通信は一切使用しない。
- **ビルド不要**: そのままブラウザで開く・静的サーバーに配置するだけで動作する。

### 6.2 パフォーマンス・安定性
- **ドローコール最適化**: インスタンシング描画（`drawElementsInstanced`）または結合頂点バッファを活用し、数千〜数万規模のボクセルを低負荷で描画する。
- **バックグラウンド省電力**: `document.visibilityState === 'hidden'` の間は描画ループを自動停止し、復帰時に時刻差分が跳ねないよう安全に再開する。
- **レスポンシブ対応**: 16:9 / 16:10 / 21:9（ウルトラワイド） / 縦画面など任意のアスペクト比・ウィンドウリサイズに自動で追従し、浮遊城が画面外に見切れないようカメラ視野角（FOV）・配置を調整する。
- **WebGL コンテキストロスト対策**: `webglcontextlost` / `webglcontextrestored` をハンドリングし、スリープ復帰等でも破綻しないようにする。
- **セキュリティ**: XSS の原因となる安全でない DOM 操作（`innerHTML` への未検証文字列挿入等）を避け、`textContent` ベースで安全に UI を構築する。

## 8. 受け入れ基準

1. `index.html` を静的サーバー経由（HTTPS / localhost）で開いた際、外部通信ゼロで 3D ボクセルの浮遊城シーンがフルスクリーン描画されること。
2. 浮遊城の浮遊、雲海の流れ、手前の草の揺れ、崖の滝の水流・水しぶき、光粒・光の筋、時間帯の変化が滑らかに動作すること。
3. 通常時は UI が一切表示されず、`H` キーまたは画面右下隅クリックで設定パネルを開閉でき、時間帯・品質プリセット・一時停止が反映および `localStorage` に保存されること。
4. ブラウザのコンソールエラー・WebGL シェーダーコンパイルエラー・構文エラー（`node --check`）が `0` であること。
5. `README.md` および全ファイルに既存作品の固有名詞・著作権侵害の恐れがある記述が含まれていないこと。
